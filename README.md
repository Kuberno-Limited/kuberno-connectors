# Kuberno - AI platform connectors

Official connectors published by [Kuberno](https://kuberno.com) that let AI assistants search and read your Kube corporate-registry data — entities, officers, appointments, compliance dates, and roles.

## Claude

The Kube plugin for Claude Code and Cowork lives in [`claude/`](./claude). Install it from the plugin marketplace:

```bash
claude plugin marketplace add Kuberno-Limited/kuberno-connectors
claude plugin install kube-by-kuberno@kuberno
```

See [`claude/README.md`](./claude/README.md) for the full tool list, requirements, and example prompts.

## Microsoft 365 Copilot

The Kube declarative agent for Microsoft 365 Copilot lives in [`m365-copilot/`](./m365-copilot). Download the installable package:

<https://github.com/Kuberno-Limited/kuberno-connectors/releases/latest/download/kube-copilot.zip>

Then hand it to an **AI Administrator** or **Global Administrator**, who uploads it in the [Microsoft 365 admin center](https://admin.cloud.microsoft/#/agents/all).

See [`m365-copilot/README.md`](./m365-copilot/README.md) for requirements, install steps, and example prompts.
